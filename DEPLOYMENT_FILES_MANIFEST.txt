📋 ENVIRONMENT VARIABLES
================================================================================

Backend Variables (Set in Vercel):
  DJANGO_SECRET_KEY ............... Secret key for Django
  DJANGO_DEBUG .................... False (production)
  DJANGO_ALLOWED_HOSTS ............ Your domain(s)
  DATABASE_URL .................... PostgreSQL/MongoDB URL
  MONGODB_URI ..................... MongoDB connection string

Frontend Variables (Set in Vercel):
  VITE_API_BASE_URL ............... Backend URL
  VITE_APP_NAME ................... Application name

See .env.example for complete list and descriptions.

📞 QUICK COMMANDS
================================================================================

Verify Setup:
  vercel --version
  vercel whoami

Deploy:
  vercel              # Preview
  vercel --prod       # Production
  vercel --prod --force # Force rebuild

Monitor:
  vercel list         # List deployments
  vercel logs --prod  # View logs
  vercel logs --prod --follow # Real-time logs

Manage:
  vercel env list     # List variables
  vercel env add NAME # Add variable
  vercel rollback     # Rollback
